Welcome to **shine.away.log**. This is the first note.

The blog is built with Next.js, MDX, and Tailwind CSS, and is statically
exported to GitHub Pages. Posts are just MDX files under `content/posts`.

## Writing posts

Each post is a Markdown/MDX file with frontmatter:

```md
---
title: "Hello, world"
date: "2026-09-02"
summary: "A short summary."
tags: ["meta"]
---
```

Because it's MDX, you can also drop in React components when you need them.

- Simple to write
- Statically generated
- Fast to load

That's it for now.
