# 블로그 홈 태그 목록

블로그 홈 상단의 소개 영역 아래, 최근 글 목록 위에 이 블로그에서 사용된 모든 태그를 탐색 가능한 pill 링크로 표시한다. 태그는 사용 빈도순으로 제공하며 기존 태그별 게시글 페이지로 연결한다.

공유된 요구사항과 검증 기준은 [facts.md](./facts.md)를 따른다. 승인된 구현 순서와 검증 방법은 [plan.md](./plan.md)를 따른다.

## Done condition

`facts.md`의 모든 승인된 사실이 구현되고, 계획에 명시된 자동 테스트·lint·정적 export 빌드가 통과하며, 모바일/데스크톱 및 라이트/다크 테마에서 태그 pill의 줄바꿈과 가독성을 수동 확인하면 완료다.
